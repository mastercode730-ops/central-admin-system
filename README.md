# 🚀 Central Admin System

Centralized multi-tenant management portal and API engine for controlling 40–50+ websites without code editing or redeployments.

## Features
- 📱 **Bulk WhatsApp Redirection Updater**: 1-click number and greeting update across all sites.
- 🔍 **Google Search Console Token Deployer**: Instant verification meta tag deployment.
- 📝 **Word Doc (.docx) Blog Publisher**: Drag-and-drop `.docx` articles with automatic HTML conversion.
- 🎨 **Solution 1 Dynamic Banner Engine**: Automatically generates 1200x630 SEO-ready OpenGraph banners matching website niche/theme.
- 🔌 **Plug & Play Client SDK**: Universal 1-line script integration for React, Next.js, Vite, or HTML sites.

## Quick Start
```bash
npm install
npm start
```
Default port: `http://localhost:5000`

## Deployment
Compatible with Render, Railway, DigitalOcean, VPS (Hostinger, AWS, Ubuntu), and Docker.
