How to Connect Any Website to the Central Control Hub

Follow this simple 2-step guide to connect your React, Next.js, or HTML websites so that WhatsApp numbers, Google Search Console codes, and Blogs can be managed centrally without future code redeployments.

1

Register on Central Portal

Open the admin portal, click + Add, and enter your Website Name and Domain. This generates your unique Site ID.

Portal: central-admin-system.onrender.com
2

Add 1 Line to Website Code

Paste the lightweight client.js script tag into your website's index.html or layout.js with your data-site-id.

<script src=".../client.js" data-site-id="...">
3

Done! Zero Redeployment

WhatsApp numbers and GSC tags will now update in real-time on the live site whenever changed in the Admin Portal.

Framework Integration Examples

      


      


        
        

          

            

               React / Vite Projects
            

            index.html
          

          

            Open the root index.html of your React/Vite project and paste this script tag inside the <head> tag:
          

          
<!doctype html>
<html lang="hi">
  <head>
    <meta charset="UTF-8" />
    <title>My Site Title</title>
    <!-- Central Admin Control Script -->
    <script src="https://central-admin-system.onrender.com/client.js" data-site-id="YOUR_SITE_ID" async></script>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>

        


        
        

          

            

               Next.js (App Router 13/14/15/16)
            

            app/layout.js
          

          

            Open app/layout.js (or layout.tsx) and add the script tag inside the <head> element of your RootLayout:
          

          
export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <head>
        <script src="https://central-admin-system.onrender.com/client.js" data-site-id="YOUR_SITE_ID" async />
      </head>
      <body>{children}</body>
    </html>
  );
}

        


      

    


    
    


      
      

        

          
          
How to Add the Dynamic Blog Page

        

        

          If your website has a Blog page (e.g., /blogs or /blog.html), you can render all articles uploaded from Word documents automatically using our widget:
        

        
<!-- Drop this in any page to show blogs -->
<div id="central-blog-container"></div>
<script src="https://central-admin-system.onrender.com/blog-widget.js" data-site-id="YOUR_SITE_ID" async></script>

      


      
      

        

          
          
Dynamic Google XML Sitemap

        

        

          The central system automatically maintains a live Google-compliant XML sitemap for every website. You can submit this directly to Google Search Console:
        

        

          https://central-admin-system.onrender.com/api/v1/sitemap.xml?siteId=YOUR_SITE_ID
